## **Описание**

Правило автоматизации отменяет задачу экспертизы Windows в рабочем процессе запроса на изменение ВМ, если среди создаваемых и удаляемых по запросу дисков нет ни одной виртуальной машины на ОС Windows с администрированием ОС. Правило привязано к шаблону задачи автоподготовки «Авто. Изменение ВМ.Подготовка РП» и запускается после задержки по времени. Оно разбирает JSON-перечни создаваемых (json_create) и удаляемых (json_delete) ВМ из полей запроса, по каждому ID находит КЕ виртуальной машины и проверяет два признака: семейство ОС — Windows и режим администрирования — «Администрирование ОС». Если такой ВМ нет ни среди создаваемых, ни среди удаляемых (по 10 позиций в каждом перечне), задача экспертизы Windows переводится в статус «Отменено» с добавлением поясняющего комментария.

## **Описание**

<c #0f1115>Правило автоматизации автоматизирует проверку списка лиц после согласования (РП) и завершает задачу проверки, если согласующие лица определены. Если итоговый список лиц, подлежащих проверке, не пуст — задача проверки переводится в статус «Завершено» со служебной пометкой, а все связанные согласования отменяются.</c>

</td><td>
`workflow.tasks.detect(category = approval).custom_fields.person_count` — количество лиц в задаче согласования (категория approval) текущей задачи проверки
</td></tr><tr><td>
is_all_save
</td><td>
`to_dismiss_count = null` — проверка, что количество лиц не определено (null), то есть список пуст
</td></tr><tr><td>
is_assigned
</td><td>
`status = assigned` — проверка, что статус задачи проверки «Назначена»
</td></tr><tr><td>
greater_than_40
</td><td>
`to_dismiss_count > 30` — количество лиц превышает 30
</td></tr><tr><td>
current_template_id
</td><td>
`template.id` — идентификатор шаблона текущей задачи проверки (35503)
</td></tr><tr><td>
option_1_to_cancel
</td><td>
`workflow.tasks.reject(template.id = current_template_id).reject(status = completed).reject(status = canceled).reject(status = approved).reject(template.id = 35560)` — задачи на отмену: все задачи рабочего процесса, исключая саму задачу проверки, уже завершённые, отменённые, одобренные и задачи шаблона 35560
</td></tr><tr><td>
option_2_to_cancel
</td><td>
`workflow.tasks.reject(template.id = current_template_id).reject(status = completed).reject(status = canceled).reject(status = approved).reject(template.id = 35476).reject(template.id = 35475).reject(template.id = 7411).reject(template.id = 4313)` — задачи на отмену: аналогично option_1_to_cancel, но также исключаются задачи шаблонов 35476, 35475, 7411, 4313
</td></tr><tr><td>
tasks_to_cancel
</td><td>
`greater_than_40 ? option_1_to_cancel : option_2_to_cancel` — итоговый список задач на отмену: если количество лиц превышает 30, используется option_1_to_cancel, иначе — option_2_to_cancel
</td></tr></table>

## Действия
